## 설계 원칙

1. **로컬 우선** — 내 데이터는 내 컴퓨터의 파일 하나. 백업 = 파일 복사.
2. **비밀값은 DB 밖** — 환경변수 이름만 저장.
3. **추측하지 않는 상태 표시** — 근거가 없으면 "미확인".
4. **사업 단위 분리** — 모든 레코드는 사업에 속하거나 명시적으로 "공용".
